# موقع COC الفنية – مغاغة

هذه نسخة ثابتة جاهزة للنشر مجانًا.

الملفات:
- index.html: الصفحة الرئيسية
- style.css: التصميم الأحمر المتجاوب مع الموبايل
- script.js: فتح فصلي COC 1/1 و COC 1/2 وعرض جداول الحصص

## تعديل مواعيد الحصص
افتح script.js وابحث عن `schedules`.
غيّر النص الموجود بجانب كل حصة، مثل:
["الحصة 1","08:00 - 08:45"]
